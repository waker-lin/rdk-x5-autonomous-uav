## 开源项目与文档

- [VINS-Fusion](https://github.com/HKUST-Aerial-Robotics/VINS-Fusion)：HKUST Aerial Robotics Group 的多传感器状态估计项目。
- [EGO-Planner](https://github.com/ZJU-FAST-Lab/ego-planner)：ZJU FAST Lab 的局部轨迹规划项目。
- [MAVROS](https://github.com/mavlink/mavros)：ROS 与 MAVLink 通信组件。
- [XTDrone](https://github.com/robin-shaun/XTDrone)：基于 PX4、ROS 与 Gazebo 的无人机仿真平台。
- [OpenCV 文档](https://docs.opencv.org/4.x/)：颜色分割、形态学和轮廓处理接口。

开源组件的代码和算法归相应原作者，使用时应遵守各项目许可证。团队图片和视频未单独约定开源许可。
